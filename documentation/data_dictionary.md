# Data dictionary

All records in this project are synthetically generated by the experiment script. They are not scraped product listings, verified vehicle-fitment records, or real customer messages.

## data/catalog.csv

| Field | Type | Meaning |
|---|---|---|
| id | Integer | Synthetic product-record identifier used as the relevance label. |
| part | String | Canonical automotive component category. |
| vehicle | String | Vehicle label associated with the synthetic record. |
| title | String | Synthetic product title in the form “part for vehicle”. |
| doc | String | Synthetic retrieval text assembled from a predefined part alias, vehicle label, qualifier, and brand-like token. |

## data/queries.csv

| Field | Type | Meaning |
|---|---|---|
| q | String | Generated Roman-script Hinglish-style query. |
| level | Categorical | clean, light, or heavy query-variation condition. |
| gold_id | Integer or empty | Correct catalog ID when the requested part–vehicle pair exists; empty when the pair is absent. |
| part | String | Canonical target component used by the generator. |
| vehicle | String | Canonical target vehicle used by the generator. |

## results/results.json

The JSON contains results for each retrieval method and query stratum.

- n is the number of answerable queries in the stratum.
- top1 and top3 are proportions, not percentages.
- top1_ci contains lower and upper 95% percentile-bootstrap bounds.
- abstain stores an exploratory score-threshold calculation from the original script. It is not interpreted as a validated abstention result because raw score scales are method-dependent and no calibration procedure was evaluated.

## Synthetic-data scope

The generator uses 12 component categories, 10 vehicle labels, eight query templates, predefined aliases, and handcrafted spelling perturbations. The dataset contains 180 query records, of which 164 are answerable and 16 are unanswerable. The 180 rows contain 173 unique query strings.

The data do not include model years, vehicle variants, manufacturer part numbers, prices, stock status, or verified compatibility information.
